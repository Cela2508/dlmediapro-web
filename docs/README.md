# Índice de Documentación y Snippets de DL Media Pro

Este directorio consolida las notas técnicas, snippets de implementación, recomendaciones de arquitectura y recursos visuales del proyecto.

---

## 1. `docs/snippets/` — Códigos de Implementación Web
Fragmentos de código listos para su uso en la web y el servidor:
- **`01_forzar_https_htaccess.txt`**: Reglas mod_rewrite y cabeceras HSTS para Apache/LiteSpeed (ya aplicadas en `.htaccess`).
- **`02_cookie_banner_html.txt`**: Marcado HTML y textos para el aviso legal y amigable de Cookies.
- **`03_open_graph_tags.txt`**: Metadatos Open Graph y Twitter Cards para previsualización enriquecida en WhatsApp, Facebook y LinkedIn.
- **`04_validacion_formulario_js.txt`**: Validación atómica de campos obligatorios y formato de correo electrónico.
- **`05_google_analytics_ga4.txt`**: Script de instalación para Google Analytics 4 (GA4 ID configurado en `index.html`).
- **`06_antispam_honeypot.txt`**: Técnica Honeypot invisible para protección de formularios contra bots sin recaptcha invasivo.

---

## 2. `docs/guias-seo/` — Guías Técnicas y Estándares SEO
Lineamientos para el desarrollo y posicionamiento:
- **`01_variables_entorno_env.txt`**: Buenas prácticas de seguridad para tokens y variables de entorno backend.
- **`02_metadescripciones_seo.txt`**: Variantes de metadescripciones optimizadas para CTR (≤ 155 caracteres).
- **`03_especificaciones_favicon.txt`**: Medidas canónicas para favicon.svg, PNG 32x32 y Apple Touch Icon 180x180.
- **`04_media_queries_responsivo.txt`**: Enfoque Mobile-First, tipografía fluida con clamp() y touch targets mínimos de 44x44 px.

## 3. `docs/recursos-graficos/` — Infografías y Referencias Visuales
Referencias para el equipo de diseño y contenido:

- **`ejemplos_cta_alta_conversion.png`**: 3 ejemplos de llamadas a la acción con alta tasa de clics.
- **`herramientas_gratuitas_recomendadas.png`**: Herramientas recomendadas para compresión, optimización y diseño web.
